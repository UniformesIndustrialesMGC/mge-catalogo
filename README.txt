# MGE Textiles + Uniformes - Catálogo Web

Página web estática gratuita para mostrar productos y recibir cotizaciones por WhatsApp.

## Archivos

- index.html
- style.css
- script.js
- imagenes/

## WhatsApp

El botón flotante muestra dos números:
- 222 136 5686
- 221 464 198

Los botones de producto abren directamente WhatsApp con el producto incluido en el mensaje.

## Para cambiar los números

Edita `index.html` y busca `wa.me/`.

## Para agregar productos

Copia una tarjeta `<article class="product-card">...</article>` dentro de `.products`, agrega la imagen a `imagenes/` y cambia el nombre/descripción.

## Publicación gratuita

Puedes subir esta carpeta a GitHub Pages, Cloudflare Pages o Netlify.
